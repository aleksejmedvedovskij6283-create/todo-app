# todo-app — лабораторные работы № 6 и № 7

Консольное приложение «Список дел» на Python.

## Запуск

```bash
python main.py
```

Данные сохраняются в `tasks.json` в корне проекта. При первом запуске файл создаётся после выхода из программы.

## Запуск автоматических тестов

```bash
python -m unittest -v
```

Тесты `test_logic.py` проверяют классы `Task` и `TaskManager`; `test_storage.py` проверяет JSON-хранилище во временной папке.

## Реализовано

- сериализация `Task` через `to_dict()` и `from_dict()`;
- класс `Storage` для чтения и записи JSON в UTF-8;
- загрузка при запуске и сохранение при выходе;
- обработка отсутствующего и повреждённого файла;
- тесты `unittest`, фикстуры `setUp`/`tearDown`, временные файлы;
- сортировка задач по сроку (`get_sorted_by_deadline`);
- дополнительная проверка даты в формате `ГГГГ-ММ-ДД`.
